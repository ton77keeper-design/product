## Русский

GulDia — это интерактивный прототип сервиса доставки продуктов из локальных супермаркетов в стиле **Wolt / Chocofood**.

### 🎯 Основные функции

✅ **Три роли:** Покупатель | Курьер | Админ  
✅ **Каталог:** Магазины, товары, поиск, фильтры  
✅ **Заказы:** Корзина, оформление, отслеживание статуса  
✅ **Лояльность:** 5% кэшбэк, VIP-уровни, баллы  
✅ **Отзывы:** Рейтинги магазинов и товаров ⭐  
✅ **Уведомления:** История сообщений 🔔  
✅ **Поддержка:** Чат с ботом 💬  
✅ **Профиль:** Статистика трат и история 📊  

### 🚀 Быстрый старт

```bash
bun install
bun run dev
# http://localhost:8080
```

### 📁 Стек

- **React 19** + **TanStack Start v1** (SSR на Cloudflare)
- **Zustand** для состояния
- **Tailwind CSS v4** для стилей
- **framer-motion** для анимаций
- **TanStack Router** для роутинга

## English

GulDia is an interactive prototype of a grocery delivery service from local supermarkets in the style of **Wolt / Chocofood**.

### 🎯 Key Features

✅ **Three Roles:** Customer | Courier | Admin  
✅ **Catalog:** Stores, products, search, filters  
✅ **Orders:** Cart, checkout, order tracking  
✅ **Loyalty:** 5% cashback, VIP tiers, points  
✅ **Reviews:** Store and product ratings ⭐  
✅ **Notifications:** Message history 🔔  
✅ **Support:** AI chatbot 💬  
✅ **Profile:** Spending stats & order history 📊  

### 🚀 Quick Start

```bash
bun install
bun run dev
# http://localhost:8080
```

### 📁 Stack

- **React 19** + **TanStack Start v1** (SSR on Cloudflare)
- **Zustand** for state management
- **Tailwind CSS v4** for styling
- **framer-motion** for animations
- **TanStack Router** for routing
