# GulDia — доставка продуктов из супермаркетов (веб‑прототип)

GulDia — это интерактивный прототип сервиса доставки продуктов из локальных супермаркетов в стиле Wolt / Chocofood.

## 🎁 Новые функции

- ⭐ **Рейтинговая система** — оценки и отзывы магазинов
- 🔔 **Уведомления** — история сообщений
- 📊 **Статистика** — анализ трат пользователя
- 🎯 **Рекомендации** — персональные товары
- 💬 **Чат поддержки** — форма обратной связи
- 🏆 **Лояльность** — программа баллов

## 🚀 Запуск

```bash
bun install
bun run dev  # http://localhost:8080
```
